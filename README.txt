拾刻 v1.0.0 — 使用说明
=========================

拾取与雕刻，专注于流放之路的装备加工辅助。
集合洗词缀、连点、一键回城等多合一功能。

【快速上手】
1. 启动本工具，打开流放之路（窗口/全屏窗口模式）。
2. 在「配置」页选择洗词缀模式（一般选 Mode 1 单通货）。
3. 点击货币卡片选中通货 → 鼠标悬停在游戏通货上 → 按 F7 保存坐标。
4. 同理设定“装备坐标”。
5. 在下方的词缀池中，输入你想要的主词缀（如：最大生命），点击添加。
6. 按 F5 启动，享受自动洗装。按 F6 停止。

【模式详解】
- Mode 1（单通货）：使用混沌/改造等单一通货直接重铸装备。
- Mode 2（改造+增幅）：先用改造洗出“1条”好词缀，再自动补增幅石。命中词缀总数不能超过2。
- Mode 3（改+增+富）：在 Mode 2 基础上自动上富豪石，冲多词缀金装。可选富豪后崇高。只要用来洗星团。命中词缀总数不能超过3。

【词缀规则】
- 主词缀：必须命中的目标词缀（如 T1 生命）。
- 次级词缀：多条词缀选择。通常只在mode3使用。比如洗星团可以选择A+BC/CD/BD 或者AB+C/D/E ，需要自己设定主/次命中数来调整规则。
- 排除词缀：一旦出现立刻跳过。
- 词缀预设：配置好词缀后可点击💾保存，下次直接在下拉框“配置预设”中一键调用。

【默认热键】（所有热键均可自定义）
F5：启动洗词缀
F6：停止洗词缀
F7：保存鼠标坐标
F8：连点器开关（再按停止）
F11：连点器按住模式（长按触发，松手停止）
F9：按键循环开关（模拟刷图/引荐等）
F2：一键回藏身处（需在设置页开启）

【进阶特性】
- 锁定进程：设置 > 目标进程，勾选后热键仅在 POE 窗口生效，避免误触。
- 音效自定义：设置 > 声音提醒，支持替换本地 WAV 等文件。
- 数据统计：工具启动时仅匿名上报应用名与日期。点设置页「查看统计」可核实。

【紧急停止】
按 F6 无效时，迅速将鼠标甩动至屏幕左上角触发紧急中断。

【用户反馈】
如有 Bug 或功能建议，请点击主窗口左下角「📩 反馈」提交。

【注意事项】
- 通货耗尽：若连续多次重铸装备名称不变，工具将自动停止并提示。
- 系统托盘：点 X 关闭窗口会最小化到任务栏托盘，右键图标可退出。
- 声明：工具完全不接触游戏内存，仅安全模拟键鼠操作。
